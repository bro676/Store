هل الأسعار المعروضة حقيقية؟

لا. الأسعار والأسماء المعروضة توضيحية لاختبار تجربة الاستخدام، ولا تمثل قائمة بيع معتمدة.

هل يتم تنفيذ الطلبات فعلياً؟

بعد إعداد API على الخادم، ينشأ الطلب في قاعدة البيانات ولا يُعتمد كمدفوع إلا بعد التحقق من عملية شام كاش. تنفيذ الخدمة بعد الدفع يحتاج ربط نظام التسليم بشكل منفصل.

هل شام كاش مفعّل؟

يتحقق الخادم من حالة المحفظة والفاتورة ورقم التحويل والمبلغ والوقت، ويمنع إعادة استخدام رقم العملية.

يمكنك استخدام زر واتساب أو البريد الإلكتروني الموجودين في صفحة الدعم.
